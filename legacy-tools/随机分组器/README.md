# 🎲 随机分组器

> 课堂随机分组工具：按组数或每组人数一键分组，支持避免重复搭档、锁定分组、手动拖拽调整与导出。

## ✨ 特点

### 名单

- 粘贴名单，每行一个名字，也支持逗号 / 顿号 / 分号 / 制表符分隔
- 自动去重（忽略大小写），并提示去掉了几个重复项
- 实时人数统计 + 名单预览
- 支持从 `.txt` / `.csv` 文件导入，或一键载入 30 人示例名单

### 分组

- **两种模式**：按组数分（组内人数自动均衡，差不超过 1）/ 按每组人数分（组数自动算）
- **公平随机**：用 `crypto.getRandomValues` 做无偏取样的 Fisher–Yates 洗牌，不是 `Math.random`
- **避免重复搭档**：多轮活动重新分组时，尽量不重复上一轮的同组搭档
- **锁定分组**：锁定的组在重新分组时保持不变，其余成员重新洗牌
- **待分配池**：把某人移出后单独存放，可「全部归队」放回第一组

### 结果

- 拖拽成员即可在组间调整；**待分配池里的成员同样可以直接拖回任意组**
- 拖起来时所有可放置区域（各组 + 待分配池）会同时描出虚线框，鼠标扫过去高亮当前落点；锁定的组不参与高亮
- 触屏设备也可点成员选中后再点目标组
- 组名可点击直接改（如「红队」「1 号桌」）
- 统计条：总人数、组数、平均每组、人数区间
- 撤销（`Ctrl/⌘ + Z`）、复制单组 / 全部、导出 TXT / CSV、打印（自带打印样式）
- 名单与结果自动存 `localStorage`，刷新不丢

### 界面

- 沿用站内 Claude 设计令牌，跟随右上角主题按钮切换浅色 / 深色
- 组卡片用 8 色主题色区分，深浅两种模式下都能分辨
- 尊重 `prefers-reduced-motion`

## ⌨️ 快捷键

| 键位 | 作用 |
|---|---|
| `Ctrl / ⌘ + Enter` | 立即分组 / 重新分组 |
| `Ctrl / ⌘ + Z` | 撤销上一次操作 |
| `Esc` | 取消「选中待移动」的成员 |

## 🛠️ 技术

纯 HTML + CSS + 原生 JavaScript，无构建、无依赖。样式复用 `../_shared/design-tokens.css`。
