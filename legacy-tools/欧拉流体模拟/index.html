欧拉流体模拟

基于 MAC 交错网格 + Stable Fluids 投影法的欧拉视角流体演示：物理量（u, v, p, dye）定义在固定的网格上，
每步顺序：addForces → advect → diffuse → ∇·u → Jacobi(p) → project → advect(dye)。
默认视图为俯视的向量场（u 方向 + 长度 = \|u\|），染料用深蓝 → 紫 → 珊瑚红 的渐变映射浓度。
