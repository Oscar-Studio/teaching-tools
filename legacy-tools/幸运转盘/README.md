# 🎡 幸运转盘

> 把任何一组选项丢进转盘，随机转出一个结果。课堂提问、活动安排、决定顺序、随手做个小决定都行。

## ✨ 特点

- 通用选项，不预设「抽人」场景 —— 选项是文字，你想放什么放什么
- Canvas 绘制转盘，最多 60 项，扇区按权重自动分配面积
- 支持加权语法：`选项*3` 表示机会是别人的 3 倍
- 一次抽 1 / 2 / 3 个，可开「抽后移除」避免重复
- 6 组内置预设（是否 / 星期 / 1–20 / 月份 / 颜色 / 天气）
- 结果历史可回看，一键把抽中的选项放回转盘
- 音效 + 彩带庆祝、`Space` 快捷开转、链接可分享选项

## 🛠️ 技术

纯 HTML + CSS + JavaScript，单文件无依赖。转盘用 Canvas 2D 绘制，音效用 Web Audio API 合成。
