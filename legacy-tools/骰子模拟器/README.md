# 🎲 骰子模拟器

> 真 3D 立方体骰子，支持 1～6 颗同时投掷。

## ✨ 特点

- 每颗骰子是 6 个面拼成的实心 3D 立方体，固定俯视角，落定后直接看清朝上的点数
- 抛起 → 空中翻滚 → 落地压扁回弹，地面阴影随高度同步缩放
- 骰子数量 1～6 颗，骰子面数 2～6 面（面数少于 6 时用不到的面留空）
- 朝上的面永远等于掷出的点数（由值反解旋转角，不是贴图假装）
- 点击单颗骰子可单独重掷，`Space` 一次性投掷全部
- 历史记录保留最近 10 次

## 🛠️ 技术

纯 HTML + CSS + JavaScript，单文件无依赖。

CSS 3D 立方体（`transform-style: preserve-3d`）+ Web Animations API 关键帧抛掷动画。
实现要点见 `docs/docs/teaching-tools/骰子模拟器.mdx` 的「技术实现」。
