# 📈 函数图像

> 动态演示一次函数 `y = kx + b` 与二次函数 `y = ax² + bx + c` 的图像，顶部可一键切换。拖动滑块改变参数，实时观察图像、关键点与判别式的变化。

## ✨ 特点

- **双模式切换**：顶部胶囊切换一次 / 二次函数
- **滑块实时调参**：一次函数调节 `k`（斜率）与 `b`（截距）；二次函数调节 `a`、`b`、`c`
- **关键点高亮**：一次函数显示斜率、截距、与 x/y 轴交点；二次函数额外显示顶点、对称轴、判别式
- **智能分析**：自动判别二次函数 `Δ = b² − 4ac`，给出实根个数与位置
- **可视化标注**：抛物线上自动绘制对称轴虚线、顶点圆点、x 轴交点
- **Editorial 风格**：暖米色画布 + 深海军色画板 + 珊瑚色强调，参照 Claude 设计令牌
- **一键重置**：快速回到默认参数

## 🎨 设计

- 色板：暖米色画布 `#faf9f5`、深海军色画板 `#181715`、珊瑚色 CTA `#cc785c`
- 字体：标题用 Tiempos / EB Garamond serif，公式排版为衬线斜体；正文用 Inter / 系统 sans
- 节奏：cream → cream-card → dark-mockup → cream-card → coral-callout，按 Claude 规范交替

HTML + CSS + JavaScript（Canvas 绑图），零依赖。
