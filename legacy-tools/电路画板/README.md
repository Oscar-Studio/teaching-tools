# 电路画板

初中物理「电路」单元的作图与互转工具。**实物图**和**电路图**不是两份独立的数据，而是同一份电路连关系的两种投影——所以两者可以无损地来回转换。

## 核心概念：netlist 是唯一真理源

```
                Circuit（唯一数据源）
          components[] + wires[]
                 │
                 ├─ union-find ──► nets[]   ← 推导，不存储
                 ▼
       ┌─────────┴─────────┐
   实物图渲染器            电路图渲染器
   元件散放 + 红黑导线      GB/T 4728 符号 + 规范排布
```

连通关系**不是"画"出来的，是"算"出来的**（并查集），因此：

- 用户改一根线，两个视图同时更新
- 「一键转换」不是图像转换，而是**换渲染器 + 重新排布**，连接关系永远保持
- 转换可逆，反复转换不会累积误差

这个区分不是我自创的：GB/T 4728 各分册符号条目的「应用类别」栏本身就列了**电路图 / 接线图 / 功能图**三种。本工具的 schematic ≈ 电路图，pictorial ≈ 接线图。

## 功能

| 能力 | 说明 |
|------|------|
| 画电路图 | 内嵌 SVG，手写指针交互，零运行时依赖 |
| 画实物图 | 元件按**拓扑顺序蛇形排列**，电源在链条起点，相邻的元件才是接在一起的；导线**按极性着色**（接正极红、接负极黑、其它灰），配色走 CSS 变量、深色主题自动换成看得见的浅色；**接线柱跟着所在节点的电位上色**，规则和导线完全一致，于是「这根线的颜色 == 它插着的那个柱的颜色」，不用再对柱子的位置 |
| 一键互转 | 实物图 ⇄ 电路图，共享同一份连通关系 |
| 自动排布 | 主回路排成矩形，并联支路上下对齐，电源竖放居中 |
| 自动走线 | 每根导线单独算出**正交折线**，绕开所有元件，拐角倒圆。拖动元件后自动重算，不会把线埋在元件底下 |
| 选中删除 | 点元件或点导线即选中，其上方浮出工具条（旋转 + 删除）；也可用 Delete |
| 拓扑识别 | 自动判定单回路串联 / 并联 / 串并联混合 |
| 电路检查 | 悬空接线柱、元件短路、电流表并联、电压表串联、电压表直接并在电源两端、回路不闭合 |
| 导出 | PNG / SVG / JSON（可再导入） |
| 分享 | 链接把电路编码进 `?d=`，复制即分享 |
| 其他 | 撤销重做、localStorage 自动保存、亮暗主题适配 |

## 元件库

电源（电池组）、小灯泡、电动机、发光二极管、开关、定值电阻、滑动变阻器、电流表、电压表、保险丝。

每个元件都实现了两套画法（`schematic` 电路图符号 / `pictorial` 实物图外观），共用同一套 `pins`。

开关符号依 GB/T 4728.7 **S00227 动合触点—一般符号**：左端引线收在一个空心圆上（刀闸转轴），刀身从圆心斜起，右端只剩一条固定触点引线。闭合态刀身放平成直线（国标本来的画法），但转轴那个圆圈还在，所以仍一眼认得出是开关而不是一段普通导线。断开/闭合可在属性面板切换。

## 符号依据

电路图符号参照 **GB/T 4728**《电气简图用图形符号》：

- GB/T 4728.1 §4.5.1：符号按**从左到右信号流向**设计 → 元件默认水平，竖放靠旋转
- GB/T 4728.1 §4.4.6：缩放时形状与比例都不变 → 等比缩放
- GB/T 4728.1 §4.6：端子一般不画在元件符号上
- GB/T 4728.1 §4.4.4：符号显示在模数 M 的网格上

⚠️ **GB/T 4728.1 本身不含绝对尺寸**，§4.4.7 把详细导则转引给了 ISO 81714-1。本工具的 `M = 16px`、线宽 `0.15M` 是**工程取值**，不是国标数值。详见 `plans/2026-10-13-circuit-symbol-spec.md`。

国标是工程标准，初中教材是它的简化子集。个别符号（滑动变阻器的滑动接线柱、电池组的极数）按教材习惯做了简化，尚未逐一对齐真题。

## 操作

| 操作 | 方式 |
|------|------|
| 放元件 | 点左侧元件库，再点画布任意处 |
| 连线 | 点一个接线柱 → 再点另一个接线柱（Esc 取消） |
| 选中 | 点元件或点导线，其正上方会浮出工具条（元件是「⟳ 旋转 + ✕ 删除」，导线只有「✕ 删除」——导线没有朝向可言） |
| 移动 | 点住元件拖动（拖过就退出自动排布，转为手动布局，导线会自动绕开重排） |
| 旋转 | **点住悬浮工具条上的「⟳ 旋转」拖动**，元件跟着光标绕自己中心转（15° 一档，按住 `Shift` 放开到 1° 微调）；或双击元件转 90°；或在右侧属性里选角度 |
| 删除 | 选中后点悬浮的删除按钮，或按 Delete / Backspace |
| 缩放 / 平移 | 滚轮 / 拖空白处 |
| 撤销 / 重做 | `⌘/Ctrl+Z` / `⌘/Ctrl+Shift+Z` |

删除元件会连带删掉接在它上面的导线；删除导线只拆那一根。两者都可撤销。

## 走线为什么不在 layout 里

布局只管**元件摆在哪**，不管**线怎么走**。走线在 `layout.js` 的 `routeWire()` 里按每根 `state.wires` 单独算。这样做的原因：

1. 一段画出来的线 = 用户连的那一根，导线才能被点选、被删除；
2. 自动排布和手动拖动共用同一套走线，不必分别维护；
3. 只避让元件，不避让别的导线 —— 电路图里导线交叉本来就正常，两条线共享一段正好读作「一个接线柱在分叉」。

候选折线（L 形 2 种 + 中点 Z 形 2 种 + 贴着障碍物外沿的绕行通道）按「压到几个元件 → 总长 → 弯折数」打分取最优，`orthoPath()` 再把直角倒成圆角。

走线的起终点是引脚外侧的 `stub()`（引出机身一小段），不是引脚本身 —— 这样**两端元件也留在障碍集里**。早期版本把两端元件从障碍集剔除，代价是一根线可以横穿自己元件的机身：电流表 b 脚出来的线往左画过表盘再拐弯，看上去就像接在了 a 脚上。

## 接线柱为什么按节点电位上色

实物图的接线柱**不写死 a=红 / b=黑**，而是跟着这个柱所在**节点的电位**走，规则和导线完全一致（`Layout.postColors()` → `Layout.wireColor()`）。于是「这根线的颜色 == 它插着的那个柱的颜色」这句恒等式成立，看图时不用再去对柱子的位置。

写死一红一黑的问题是：串联电路里中间的元件两个柱一红一黑，看着像接了正负极，其实两根线都在中间电位，纯误导。改过来之后，中间元件就是两个灰柱、接正极的那头红、回负极的那头黑。

例外是标了 `fixedPosts` 的元件 —— **电流表、电压表**的 `+` / `−` 端、**电池组**的两极。这些端子的颜色是约定俗成的固定色，跟电路怎么接无关（电池没接成通路时也得看得出哪边是正极），所以不参与重新上色。

`parts.js` 里柱子的 `fill` 写的是 `fill:var(--post-a)` / `var(--post-b)`，实际色值注入在 art 那层 `<g>` 上。页面渲染和导出 SVG 走的是同一份 `postColors()` 结果，所以两条路径颜色必然一致（导出时由 `resolveVars()` 就地换成具体色值 —— 导出的独立文件里没有页面上的 CSS 变量，留着 `var()` 就是无效值）。

## 自测

```bash
cd teaching-tools && node test-circuit.cjs
```

纯逻辑自测，不依赖浏览器。除拓扑分析与教学校验外，还盯四条走线不变量：**端点就是引脚**、**导线不压元件**、**导线不横穿自身机身**、**几何分组不串网**；并覆盖手动摆位的别扭布局。接线柱配色也有独立断言，核心一条是**导线两端插着的柱子颜色 == 那根线的颜色**（固定色元件除外）。四个 js 都会先做一次语法解析 —— `app.js` 绑 DOM 跑不了，但少个括号在浏览器里是整页白屏，本地必须挡住。

## 已知限制

- **暂不支持电路仿真**（拨开关灯变亮、电表读数）——V0 明确排除
- **拓扑只看导线连接，不看开关通断**。开关断开时回路仍算"接通"，这是刻意的：这里画的是接线结构，不是工作状态。要判通断需要仿真，属于 V0 排除的范围
- **滑动变阻器是两端模型**，没实现教材里的四接线柱
- **只覆盖串+并联类拓扑**，更复杂的网络无法自动排布
- 导出 SVG 是给白底打印用的，符号和导线固定深色；深色主题下导出需自行调整。导出时会把页面上的 CSS 变量换成具体色值，否则接线柱会变回默认黑
