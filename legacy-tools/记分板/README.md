# 🏆 记分板

> 课堂小组竞赛计分工具，支持多组计分 + 历史趋势复式折线统计图 + JSON / CSV 导入导出。

## ✨ 特点

- 支持 2～6 组同时计分
- 每组分值加减、自定义设置
- **本地持久化**：分数、队名、历史记录都存在 localStorage，刷新或关闭后再打开恢复现场
- **历史记录**：自动保存每次比分变动
- **复式折线统计图**：每队一条折线，展示分数变化趋势（X 轴=回合、Y 轴=分数，支持中途加入队伍）
- **回合列表**：每回合的时间戳、各队得分、相对上回合的 Δ 增量
- **导入 / 导出菜单**：
  - 「📤 导出」下拉 → JSON（完整数据，含当前分数、队名、历史）/ CSV（历史记录）
  - 「📥 导入」接受 `.json` 和 `.csv`，按扩展名自动分发解析
- **格式校验**：导入时会校验 JSON 类型与版本、CSV 表头与字段；坏文件给出明确报错，不会污染状态
- **CSV 导入**：从表头反推队名，最后一行当作当前分数
- **深浅色主题**：图表自动跟随系统 / 用户设置切换配色
- 大屏显示，各组得分一目了然

## ⌨️ 键盘快捷键

| 按键 | 作用 |
|------|------|
| `1` / `q` | 队伍 1 +1 / -1 |
| `2` / `w` | 队伍 2 +1 / -1 |
| `3` / `e` | 队伍 3 +1 / -1 |
| `r` | 重置所有（带确认） |
| `f` | 全屏切换 |
| `h` | 显示 / 隐藏历史面板 |

> 焦点在输入框时自动忽略快捷键。

## 📦 数据格式

### JSON（完整）

```json
{
  "version": 1,
  "type": "oscar-studio-scoreboard",
  "exportedAt": 1786546612652,
  "teamNames": ["蓝队", "队伍 2", "红队"],
  "scores": [12, 3, 2],
  "rounds": [
    { "t": 1786546556799, "s": [1, 0] },
    { "t": 1786546557799, "s": [2, 0] }
  ]
}
```

校验规则：`type === 'oscar-studio-scoreboard'`、`version === 1`、队伍数 2~6、队名非空、分数非负有限、rounds 时间戳合法且 `s.length ≤ teamNames.length`。

### CSV（历史记录）

```csv
回合,时间,蓝队_分数,队伍 2_分数,红队_分数
1,2026-08-13 19:49:36,1,0,0
2,2026-08-13 19:49:36,2,0,0
```

- 文件带 UTF-8 BOM，Excel 打开不乱码
- 表头必须以 `回合,时间,` 开头，每列队名以 `_分数` 结尾
- 队名从表头反推；当前分数取最后一行的值；rounds 直接还原

## 🛠️ 技术

纯 HTML + CSS + JavaScript，复式折线图使用 Plotly（已随仓库打包 `plotly-2.27.0.min.js`）。

持久化键：
- `teaching-tools-scoreboard-state-v1` — 当前分数与队名
- `teaching-tools-scoreboard-rounds-v1` — 历史快照（最多 500 个回合）
