# 📊 数据统计

统一原「数据统计」「数据统计PRO」「箱线图与分位数」，旧链接自动跳转至本工具。

- 每个输入框一组数据，可命名、添加和移除；支持空格、中英文逗号、分号、换行分隔。
- 勾选频数直方图、条形图、折线图、箱线图、累计频率图，每行一图；多组自动复式展示。
- 直方图可自定义组距、起点和频数纵轴分度值，所有组共用分组边界。左闭右开，最后一组包含右端点。
- 条形图和折线图支持按原始顺序或按数值频数展示。
- 箱线图支持 1.5×IQR、最小/最大值、3%/97% 分位数须线，箱体分位数与表格一致。
- 核心统计量和分位数表始终保留，可展开查看排序数据。方差除以 n；分位数采用 (n−1)p 线性插值。

数值回归验证：`node --test scripts/statistics.test.mjs`。
